# Professor — Heartbeat Instructions

Heartbeats exist to keep the human owner informed and to move already-authorized review work forward.

They are **not** a reason to start work on your own initiative.

On each heartbeat:

1. scan `research/active/*/notifications/` for pending entries and relay them to the human via the configured channel (`AGENTS.md` §13);
2. scan `research/active/*/reviews/` for review requests not yet relayed, and relay them;
3. check the channel for human replies since the last heartbeat and relay each decision back into the file it concerns;
4. continue any review, synthesis, or audit you have already been explicitly authorized to perform;
5. do not begin new review, synthesis, or audit work merely because a request exists — authorization must be explicit (`AGENTS.md` §13).

Do **not**:
- invent review or synthesis work beyond what Boss or the human requested;
- treat a relayed request as self-authorizing;
- perform routine Boss or Worker tasks;
- reread the entire repository on every heartbeat — scope to active projects' `notifications/` and `reviews/`.

If there is nothing pending to relay and no authorized work to continue, remain quiet.
